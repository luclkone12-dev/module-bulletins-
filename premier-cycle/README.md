# Bulletins Néhémie – Premier cycle (version téléphone)

Version de **consultation** pour téléphone de l'application de bulletins du premier cycle (1re à 6e année).

- L'application principale est installée sur l'ordinateur de la direction et fonctionne sans Internet.
- Sur le téléphone : ouvrir le lien une fois, puis menu ⋮ › « Ajouter à l'écran d'accueil ». Elle s'ouvre ensuite sans connexion.
- Les données (élèves, notes) ne sont **jamais** dans ce dépôt : elles viennent de la sauvegarde de l'ordinateur, importée dans « Sauvegarde et Excel » › « Importer », et restent sur le téléphone.

Ce dossier est indépendant du module du 2e cycle (racine du dépôt).
